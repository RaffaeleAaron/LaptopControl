# Icon provenance

`laptop-control.ico` is the processor icon supplied by the project owner;
`laptop-control.png` is its application/tray rendering. These supplied artwork
files are separate from the MIT-licensed source code. Their original author,
attribution and redistribution terms have not been established in this project.
The source-code license does not grant rights to third-party artwork.

Navigation and profile symbols are original vector shapes drawn in Rust.
